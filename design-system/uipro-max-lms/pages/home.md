# Home override

MASTER 落地页是 Product Demo + Features（含视频）。CDAS 首页没有产品视频，因此改用产品库已验证的 **LMS：Dashboard + Course Grid**。

- 保留 MASTER 色板、Plus Jakarta Sans、Flat Design。
- 无渐变、无阴影；`--border-radius: 2px`；悬停只改颜色/透明度，150–200ms。
- 不放营销 hero、不放假演示视频、不引入 GSAP。
- 两个工作区入口按课程卡网格排布。
- 卡片装饰图标只用技能库已验证的 Phosphor：`pencil-simple`、`file-text`、`arrow-right`。
- 主 CTA 用 `--color-accent` / `--color-on-accent`（`#EA580C` / `#000000`）。
