# Student Dashboard Page Overrides

> Rules in this file **override** `design-system/uipro-max-lms/MASTER.md`.

---

## Page-Specific Rules

### Layout Overrides

- 产品库：**Dashboard + Course Grid**。活动按待提交 / 已提交 / 已有反馈 / 历史分组。
- 不放图表、筛选动画、假按钮或营销视频。

### Spacing Overrides

- 与教师端共用 MASTER 密度 8 token。

### Color Overrides

- 登录 / 提交类主 CTA 用 `--color-accent` / `--color-on-accent`。
- 打开活动用 `--color-accent` 字色 + `arrow-right`。

### Component Overrides

- 课程行是可点卡片：2px 边框、悬停只改背景。
- 装饰图标：`file-text`（活动）、`arrow-right`（打开）、`sign-in`（登录）。
